# Research Patch — Sucker for Love: Crush Landing

Checked: 2026-09-01. This patch supplements, and does not replace, the
original `docs/seo-research.md` Research Package audit record.

## Coverage

- Google SERP intent scan: overview, release facts, walkthrough, endings,
  achievements, characters, puzzles, and player-question intents.
- Official Steam full-game listing: premise, Hheily, genre/tone, features,
  multiple endings, release metadata, language, content note, and minimum PC
  requirements. [Steam store](https://store.steampowered.com/app/3848900/Sucker_for_Love_Crush_Landing/)
- Official demo listing, kept separate from the full-game record.
  [Steam demo](https://store.steampowered.com/app/4371660/Sucker_for_Love_Crush_Landing_Demo/)
- Official video coverage: [announcement trailer](https://www.youtube.com/watch?v=BNudA1IM6qM)
  and [Six One Indie trailer](https://www.youtube.com/watch?v=F9OsHxwyOR0).
- Steam Community: real questions about the opening wait, ending count,
  protagonist, language, and demo behavior. [Community hub](https://steamcommunity.com/app/3848900)
- Public achievement index: 19 achievements and named interaction themes;
  used as secondary evidence, not as a substitute for official route
  documentation. [Achievement index](https://www.exophase.com/game/sucker-for-love-crush-landing-steam/achievements/)
- Walkthrough/media observation: demo-only ending labels and opening/demo
  observations. [Demo longplay](https://www.youtube.com/watch?v=Of5hgko1MXw)
  and [PC Gamer demo coverage](https://www.pcgamer.com/games/sim/the-demo-of-sucker-for-love-crush-landing-is-the-gentle-reminder-i-needed-to-feel-like-a-normal-person/)
- Reddit was checked for player context and discussion, but Reddit claims are
  not promoted to verified game facts. [Sucker for Love discussion](https://www.reddit.com/r/suckerforlove/comments/1vp7ryx/game_order/)

## Evidence boundary

The patch intentionally omits invented full-game character rosters, exact
color recipes, item orders, puzzle solutions, ending conditions, and
spoiler-heavy walkthrough steps where primary evidence is not available. Demo
observations are explicitly labeled as demo/secondary evidence.

## Generation boundary

The patch is consumed as the V4 handoff input by the existing default
`site:create` flow. `primitiveData` is derived by the shared generator from
the supplied facts/evidence; no Sucker page HTML or primitive data was
hand-authored.
